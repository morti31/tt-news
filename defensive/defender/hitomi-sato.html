Defensive style

How we decide: The Chop puts every defender in one of three styles. A player is only included when a source we can open describes them as a defender; long pimples alone don't count. The type follows how the sources describe their game, and each player's page quotes the exact words. Where no source describes the game in detail, the type is our provisional call. The definitions are ours, based on:

  • Martin Spin's ranking of defensive and special styles, which describes how each player plays
  • Butterfly's coaching guide, Player archetypes: defensive styles
